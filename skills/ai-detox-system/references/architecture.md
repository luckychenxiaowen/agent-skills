## 系统集成架构

```
用户查询 / AI 搜索结果
        │
        ▼
┌──────────────────────────────────────┐
│         排毒系统 API Gateway          │
│                                      │
│  ① 文本提取 → 声明拆解 → 实体识别     │
│  ② L1 表层扫描 (100ms)               │
│     ├─ green → 放行                  │
│     └─ yellow/red → L2              │
│  ③ L2 交叉验证 (500ms)              │
│     ├─ 通过 → 放行                   │
│     └─ 可疑 → L3                    │
│  ④ L3 行为分析 (3s)                 │
│     ├─ 通过 → 放行                   │
│     └─ 可疑 → L4                    │
│  ⑤ L4 实体验证 (异步, 2-10s)        │
│  ⑥ L5 对抗演化 (持续)               │
│                                      │
│  输出: { score, evidence, flags }    │
└──────────────────────────────────────┘
        │
        ▼
  AI 搜索增强：在结果中标注可信度
  [可信] [可疑(3处数据异常)] [虚假(虚构机构)]
```

## 与 AI 搜索引擎的集成方式

### 方式 1：浏览器插件（推荐 MVP）

- Chrome/Firefox 扩展
- 拦截 AI 搜索响应，注入可信度标注
- 支持 DeepSeek/豆包/Kimi/元宝

### 方式 2：API 中间件

- 部署为微服务
- AI 搜索产品通过 API 调用获取可信度评分
- 适合企业级集成

### 方式 3：搜索前过滤

- 在 AI 搜索的检索阶段过滤低可信度信源
- 维护黑名单域名/IP 段数据库
- 降低搜索成本

## 技术栈建议

| 组件 | 推荐方案 | 理由 |
|------|----------|------|
| 实体识别 | NER 模型 (BERT-based) | 提取人名/机构/数字/百分比 |
| 常识检测 | 知识图谱 + 规则引擎 | 如 Wikidata 常识库 |
| 文本相似度 | sentence-transformers | 多语言支持，中文优化 |
| 域名验证 | WHOIS + SSL 证书链 | 检测域名年龄/注册信息 |
| 搜索引擎 API | 多引擎并行查询 | 检测各引擎结果差异 |
| 对抗训练 | 定期规则更新 + 机器学习 | 应对造假手法进化 |
